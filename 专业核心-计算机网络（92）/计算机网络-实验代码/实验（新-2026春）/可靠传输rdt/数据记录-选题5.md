# 选题 5 数据记录 — 优化时钟推进策略

> **实验者**：修改 `sim.c` 主循环中的时钟推进逻辑，使得当两个 worker 都阻塞在较远超时时可以直接跳时间。
> 用 `time` 命令测量修改前后的运行时间。
> 修改思路：在 main 中连续收到 NOTHING 时，且距最低定时器还有距离，跳过中间无意义 tick。

---

## 修改说明

修改位置：`sim.c` 主循环（约第 70-85 行）

**当前逻辑**：每次循环 `tick += DELTA`（即每次推进 10 tick）

**优化目标**：
- 追踪两个进程的挂起状态
- 当双方连续返回 NOTHING 时，计算到最近有效事件的跳跃距离
- 直接 `tick` 跳到该位置（或跳到 `last_tick`，取较小值）

**可选实现方案（供参考）**：
```
// 伪代码
if (hanging[0] > 0 && hanging[1] > 0) {
    // 双方都阻塞，可以跳跃
    tick = min(next_event_time, last_tick);
} else {
    tick += DELTA;
}
```
