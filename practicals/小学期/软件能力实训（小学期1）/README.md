## 原有课程说明

### 2023级情况说明

> **备注**：下述情况仅来自2023级学生，仅供参考

本课程成绩**完全依据CSP认证考试分数折算，完全不看签到、作业、考试等**：

- CSP 150分 ➜ 课程成绩 60分（及格）
- CSP 300分 ➜ 课程成绩 100分（满分）
- 中间分数按比例线性折算：**CSP每3.75分 = 课程1分**

**第一次成绩申报**（2026年）：4月2日 — 4月14日 16:00

> 3月29日下午第41次CSP认证考试（考完刚好可以参与本次申报）

**第二次成绩申报**（2026年）：6月1日 — 6月4日 12:00

> 5月31日下午第42次CSP认证考试（考完刚好可以参与本次申报）

**申报方式**：

届时，负责CSP认证的易老师会在院群里发通知，统一通过**线上问卷**填报申报，以群内正式通知为准

**注意事项**：

- **保研同学必看**：需要保研的同学教务系统中一定要有「软件能力实训」课程成绩
- **成绩锁定规则**：CSP成绩一旦录入教务系统，就**无法修改**
- **刷分时限说明**
  - 保研同学：建议尽早刷出理想分数，按时完成申报录入；
  - 非保研同学：最晚可在**大四第二学期4-5月**录入CSP最高成绩。
